01

Setup & theory

We have \(n\) systems and \(m\) attackers. Attacker \(j\) probes the systems one after the other and, on system \(i\), collects a score increment \(X_i^{(j)}\). Increments are independent and identically distributed, so each attacker draws an independent trajectory of the cumulative score

$$S_k=\sum_{i=1}^{k}X_i,\qquad k=1,\dots,n.$$

The map \(k\mapsto S_k\) is a stochastic process (a random walk): the probabilistic generalisation of a deterministic function. Same rule, different path for every attacker.

modelsupportlaw\(\mu=E[X]\)\(\sigma^2\)
Bernoulli{0, 1}\(P(X=1)=p\)\(p\)\(p(1-p)\)
Rademacher{−1, +1}\(\tfrac12,\tfrac12\)01

Rademacher is \(2\cdot\text{Bernoulli}(\tfrac12)-1\): a breach is +1, a repelled attack is −1. It is the symmetric, zero-mean case — the net score of a fair duel between attacker and defender.

Counting trajectories — Pascal's fan

Label on each node = number of paths reaching \(j\) breaches after \(k\) systems \(=\binom{k}{j}\). Each node is the sum of its two parents, \(\binom{k}{j}=\binom{k-1}{j-1}+\binom{k-1}{j}\). There are \(2^k\) paths, yet they pile up in the middle: hence \(P(S_n=k)=\binom{n}{k}p^k(1-p)^{n-k}\).

Total score
$$S_n=\sum_{i=1}^n X_i$$ $$E=n\mu,\quad \mathrm{Var}=n\sigma^2$$

Spread grows like \(\sqrt n\): the distribution escapes to infinity.

Average score
$$\frac{S_n}{n}=\frac1n\sum_{i=1}^n X_i$$ $$E=\mu,\quad \mathrm{Var}=\frac{\sigma^2}{n}$$

Spread shrinks like \(1/\sqrt n\): the distribution degenerates on μ (LLN).

Normalized total
$$\frac{S_n}{\sqrt n}=\frac1{\sqrt n}\sum_{i=1}^n X_i$$ $$\mathrm{Var}=\sigma^2\ \ \text{for every } n$$

The only scaling with a stable, non-degenerate shape (CLT).

Deterministic limit vs convergence in probability

$$\lim_{x\to\infty}f(x)=L\iff\forall\varepsilon>0\ \exists x_0:\ |f(x)-L|<\varepsilon\ \ \forall x>x_0$$

A random frequency can always leave any ε-band by chance, so this definition is useless for it. Instead:

$$\frac{S_n}{n}\xrightarrow{P}\mu\iff\forall\varepsilon>0:\ \lim_{n\to\infty}P\!\left(\left|\frac{S_n}{n}-\mu\right|<\varepsilon\right)=1.$$

Single trajectories may still escape; what concentrates is the probability mass.

Proof of the (weak) LLN in one line

By Chebyshev's inequality and \(\mathrm{Var}(S_n/n)=\sigma^2/n\):

$$P\!\left(\left|\tfrac{S_n}{n}-\mu\right|\ge\varepsilon\right)\le\frac{\sigma^2}{n\varepsilon^2}\xrightarrow[n\to\infty]{}0.$$

CLT and its speed

$$\frac{S_n-n\mu}{\sigma\sqrt n}\xrightarrow{d}\mathcal N(0,1)\quad\text{(Rademacher: } S_n/\sqrt n\xrightarrow{d}\mathcal N(0,1))$$ $$\sup_x\left|F_n(x)-\Phi(x)\right|\le\frac{C\,\rho}{\sigma^3\sqrt n},\quad \rho=E|X-\mu|^3,\ C\le 0.4748$$

2 · Why √n is the right zoom

Dividing by n is “too much”: the variance σ²/n vanishes and everything collapses on a point (a degenerate distribution). Not dividing at all is “too little”: the variance nσ² explodes. Dividing by √n keeps Var = σ² for every n, which is why a proper limiting shape exists — the Gaussian of the CLT. In the Bernoulli case Sₙ/√n still has mean p√n, which drifts to infinity: that is why the CLT is stated after centering, and why the Rademacher (zero-mean) model is the clean case.

3 · n systems vs m attackers

n is the sample size inside each trajectory: it drives the convergence. m is the number of independent replications: it does not make convergence faster, it only sharpens our picture of the distribution. 4 · Rademacher: net score and anomaly thresholds

With ±1 scoring the walk has no drift: |Sₙ| is typically of order √n, not n. By the CLT, P(|Sₙ/√n| > 1.96) ≈ 5%; the simulation gives at n = . This is the logic behind z-score alerting in IDS/SIEM pipelines.

09

Implementation notes

  • Reproducibility. The seed string is hashed with FNV-1a and fed to a mulberry32 PRNG; each section uses its own sub-stream (seed|matrix, seed|main, …), so the same seed always gives the same figures.
  • One pass, many n. Instead of re-simulating for each n, every trajectory is generated once up to nmax and Sₖ is recorded at ~30 log-spaced checkpoints. Cost: O(m·nmax) random draws.
  • Responsive UI. The main loop yields to the browser every ~4·10⁶ draws (async/await), and a run token cancels stale simulations when parameters change.
  • Lattice-aligned histograms. Sₙ lives on a lattice (step 1 or 2); bins are unions of whole lattice cells, so no comb artefacts.
  • Exact theory. Binomial pmf evaluated via log-Γ (Lanczos), Φ via the Abramowitz–Stegun erf approximation, Kolmogorov distance computed with ties handled exactly.
  • No chart library. All plots are drawn by hand on Canvas 2D (HiDPI-aware); only KaTeX is loaded for formulas.
